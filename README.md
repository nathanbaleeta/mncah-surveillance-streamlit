# mncah-surveillance-streamlit
An interactive Streamlit dashboard for the surveillance, analysis, and visualization of Maternal, Newborn, Child, and Adolescent Health (MNCAH) indicators.

### Pre-requisites
- Python 3.xx+
- [Streamlit](https://streamlit.io/)
- Pandas

### Quick Setup
The project uses [Pip](https://pypi.org/project/pip/) to keep track of its dependencies. To setup follow instructions below:

```bash
git clone git@github.com:nathanbaleeta/mncah-surveillance-streamlit.git

cd mncah-surveillance-streamlit

python3 -m venv venv

source venv/bin/activate

pip install -r requirements.txt
```

### Launch app
To bootstrap the app 
```
streamlit run streamlit_app.py
```
